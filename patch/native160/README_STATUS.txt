# ESP32-S3 160x128: checkpoint sumber, BELUM firmware siap flash

Status: integrasi sumber, belum dibangun untuk ESP32-S3 dan belum diuji pada papan. Paket ini bukan firmware, tidak berisi image flash, dan tidak boleh dipakai untuk flashing atau deploy.

Basis yang dimaksud: port ESP32 commit e6ec11972a8e025d7ab686a6ef3016cf52360834, berbasis inti Flipper 1.4.3, dengan sebagian penyesuaian/komponen 1.5.1 yang telah disiapkan pada baseline. Di antaranya ada kompatibilitas loader, CLI, GUI, storage, RPC dan utilitas; cakupannya parsial dan perlu diverifikasi pada build final. Ini bukan port 1.5.1 penuh.

Perubahan: menu utama, beranda, serta sebagian submenu dan daftar pengaturan fullscreen memiliki komposisi native 160x128; beranda tetap memakai frame animasi yang dihasilkan firmware. Daftar native menampilkan pilihan, nilai, penanda edit, pemisah dan status terkunci. Teks panjang atau karakter yang tidak didukung font native, dialog terkunci, tampilan vertikal, dan view yang tidak fullscreen memakai tampilan kompatibilitas agar isi tidak terpotong atau diubah. Komposisi kompatibilitas menempatkan frame 128x64 pada panel 160x128 dengan pemetaan satu piksel sumber ke satu piksel layar. Halaman lain belum semuanya ditata ulang agar memanfaatkan resolusi penuh. Jalur cadangan HAL pada 160x128 juga dibatasi 1:1 sehingga tidak meregangkan gambar jika alokasi atau transfer gagal. Pada ukuran layar lain, geometri terdahulu dipertahankan. Jika lapisan berikutnya mengubah framebuffer setelah menu native digambar, frame akhir digambar ulang melalui jalur kompatibilitas.

Perangkat target yang direncanakan: ESP32-S3 N16R8; ST7735S 160x128 landscape, SCL=12 SDA/MOSI=11 DC=15 RST=16 CS=GND; microSD CLK=40 MOSI=39 MISO=38 CS=14; tombol aktif-rendah UP=4 DOWN=5 LEFT=6 RIGHT=17 OK=8 BACK=18, COM=GND. Backlight mengikuti sambungan fisik terverifikasi. CC1101/Sub-GHz, NFC/PN532, nRF24, IR, RFID dan speaker/audio dinonaktifkan pada profil tanpa modul terkait. Pin dan layar landscape belum diuji pada build ini.

Cara integrasi: gunakan checkout baseline yang telah disiapkan secara lokal, cocokkan SELURUH SHA256 pada integration/baseline-sha256.json, lalu terapkan integration/native160_integration_only.patch dari akar checkout dengan patch -p1. Salin direktori components/gui/native160/ ke lokasi yang sama pada checkout dan salin components/furi_hal/display_geometry.h. SHA256 sejumlah sumber profil tambahan tercatat pada integration/source-requirements.json. Paket ini hanyalah perubahan terhadap baseline, bukan source lengkap; checksum baseline yang cocok pada file terbatas tidak membuktikan identitas seluruh checkout.

Uji host: jalankan bash tests/run_host_tests.sh PATH_CHECKOUT. Pengujian di lingkungan ini lulus dengan GCC 14.2, AddressSanitizer dan UndefinedBehaviorSanitizer: konversi frame, geometri 1:1, integrasi tampilan, pilihan menu, daftar native, nilai dan kunci, callback submenu dan pengaturan nyata dengan stub host, inisialisasi model, pelapisan, kegagalan transfer/alokasi, dan delapan frame animasi internal. Uji host tidak membuktikan build ESP-IDF, panel, tombol, microSD atau fungsionalitas firmware.

Belum tersedia di lingkungan ini: ESP-IDF 5.4.1, compiler xtensa-esp32s3, dependensi build terkelola dan perangkat fisik. Belum ada image baru, ukuran/alamat/checksum image hasil build, log build, uji boot, uji layar warna/orientasi, keenam tombol, microSD atau stabilitas. Vercel tidak diubah. Untuk dinyatakan selesai perlu build dari sumber dan dependensi yang tervalidasi, audit input dan image, uji perangkat, dan pemeriksaan file flasher.
