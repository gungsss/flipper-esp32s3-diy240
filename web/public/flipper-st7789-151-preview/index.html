Flipper 1.5.1
untuk ESP32-S3.

Port firmware untuk ESP32-S3 N16R8 dengan layar ST7789 240×240 8-pin dengan CS ke GPIO10, microSD SPI3, dan enam tombol. Source resmi Flipper 1.5.1 dipakai sebagai acuan; lapisan ESP-IDF dan sejumlah API disesuaikan agar dapat berjalan pada Xtensa.

Aplikasi Flipper akan menerima identitas 1.5.1-ESP32-preview. Tanggal build internal diisi otomatis oleh compiler.

Batas kompatibilitas

Ini port ESP32 berbasis perubahan terpilih dari tag resmi Flipper 1.5.1, bukan binary resmi Flipper Zero dan belum menyamai seluruh source/API/perilaku resminya.

ESP32-S3 tidak memiliki radio/periferal bawaan Flipper Zero. Fitur NFC, Sub-GHz, IR, iButton, dan LF RFID membutuhkan modul serta implementasi khusus. FAP ARM resmi tidak bisa dijalankan langsung pada Xtensa; aplikasi perlu dibangun untuk target ESP32.

Orientasi layar, tombol, microSD, BLE, USB, dan kestabilan boot tetap perlu kamu uji di board fisik. Source dan pemeriksaan CI.
