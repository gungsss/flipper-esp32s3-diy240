Port komunitas · ESP32-S3 N16R8

Flipper 1.5.1 untuk ST7735S

Firmware untuk layar ST7735S 160 × 128 dalam posisi landscape. Beberapa fitur yang memerlukan perangkat tambahan dapat dinonaktifkan.

Memeriksa firmware…

Sebelum memasang

  1. Gunakan Chrome atau Edge di komputer dan kabel USB yang mendukung data. Tutup aplikasi lain yang sedang memakai port ESP32.
  2. Pastikan rangkaian cocok dengan tabel di bawah. Lepaskan USB sebelum mengubah kabel.
  3. Centang konfirmasi, klik tombol flash, pilih port ESP32-S3, lalu ikuti petunjuk di layar.
  4. Setelah selesai, tekan RESET/EN jika perangkat tidak memulai ulang otomatis.

microSD bersifat terpisah dari firmware. Jika dibutuhkan oleh aplikasi, siapkan kartu dan isi datanya secara terpisah.

Pemasangan mengganti firmware

Area flash yang ditulis akan ditimpa. Cadangkan data yang diperlukan. Jika ada pilihan Erase device, biarkan tidak dicentang jika tidak ingin menghapus seluruh isi flash.

Gunakan Chrome atau Edge komputer dengan Web Serial.Buka halaman ini melalui HTTPS.

Flashing USB memerlukan HTTPS dan browser yang mendukung Web Serial.
