ESP32-S3 N16R8 · ST7735S 160×128 landscape

Flipper 1.5.1 ESP32 backport

Port ESP32-S3 ini memakai kanvas UI native 160×128 untuk panel ST7735S landscape. Beranda, launcher aplikasi, dan submenu umum ditata ulang agar tajam dan memenuhi layar tanpa meregangkan UI 128×64. Ini bukan firmware resmi Flipper Zero; beberapa aplikasi dan periferal Flipper asli tidak tersedia pada hardware ESP32.

Sebelum memilih build

Profil Inti cocok untuk wiring layar, microSD, dan tombol saat ini. Profil Modul mengompilasi menu CC1101, nRF24, PN532, IR, dan RDM6300; pin tambahannya hanya contoh dan perlu dicocokkan dengan skema board sebelum kabel dipasang.

Modul tidak terdeteksi otomatis. Untuk menggunakannya, pinout firmware harus sama dengan kabel yang terpasang. Profil modul memakai RDM6300 hanya-baca; iButton belum tersedia pada HAL ESP32 ini.
