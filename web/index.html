04 / BANTUAN

Kalau ada yang tidak berjalan.

Masalah paling umum saat flashing dan pemeriksaan awal.

ESP32-S3 tidak muncul saat memilih port +

Pastikan kabel mendukung data, coba port USB-C lain di board, tutup Arduino IDE atau Serial Monitor, dan periksa driver USB-UART sesuai chip board. Untuk mode download manual, tahan BOOT, tekan-lepas RST, kemudian lepaskan BOOT.

Browser tidak mendukung flashing +

Gunakan Chrome atau Edge desktop terbaru. Browser seluler tidak semuanya mendukung USB Serial; Android membutuhkan dukungan browser dan koneksi OTG. iPhone/iPad tidak mendukung flashing USB lewat halaman ini. Gunakan PC atau unduh firmware dan ikuti panduan manual.

Layar menyala tetapi tampilan kosong +

Periksa backlight BLK, VCC 3V3, GND, jalur SPI2 GPIO12/11, DC15 dan RES16. Offset panel ST7789 bervariasi; bila log boot normal tetapi gambar bergeser, driver perlu disesuaikan. Jangan langsung menghapus flash.

microSD tidak terbaca +

Periksa enam kabel SPI3: CLK40, MOSI39, MISO38, CS14, 3V3 dan GND. Gunakan FAT32, kemudian salin isi paket SD card upstream ke root microSD. Isi kartu SD terpisah dari firmware chip.

Apakah ini firmware Flipper Zero resmi? +

Bukan. Ini adaptasi komunitas dari Sor3nt/Flipper-Zero-ESP32-Port, khusus board ESP32-S3 N16R8 dan wiring DIY240. Beberapa fitur seperti NFC/Sub-GHz membutuhkan modul tambahan. Keberhasilan build tidak menjamin setiap fitur bekerja di hardware.
